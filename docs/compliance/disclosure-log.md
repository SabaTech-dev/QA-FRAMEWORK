## 1. Overview

Article 50(1) requires that individuals interacting with AI systems are informed they are interacting with AI. QA-FRAMEWORK implements this via the `DisclosureBanner` component (frontend) and this document describes the logging mechanism that records when and how disclosures are shown.

## 2. Frontend Disclosure Mechanism

### Component: `DisclosureBanner.tsx`
- **Location:** `dashboard/frontend/src/components/common/DisclosureBanner.tsx`
- **Behavior:** Renders an MUI Alert banner on pages exposing AI functionality (Landing, DashboardEnhanced, SelfHealing)
- **Persistence:** `sessionStorage` (key: `ai-disclosure-storage`) — dismissable per session, reappears on new browser sessions
- **Message:** Clear, non-misleading: *"This system uses AI-powered analysis. Results are generated by automated tools and should be reviewed by qualified personnel."*

### Store: `aiDisclosureStore.ts`
- **Location:** `dashboard/frontend/src/stores/aiDisclosureStore.ts`
- Zustand store with `persist` middleware using `sessionStorage`
- API: `dismissed` (boolean), `dismiss()`, `reset()`

## 3. Disclosure Log — What is Recorded

Each page load that renders the DisclosureBanner constitutes a disclosure event. The following table defines what is logged server-side via standard application logging:

| Field | Source | Example |
|-------|--------|---------|
| `timestamp` | Server clock (UTC) | `2026-08-14T06:25:00Z` |
| `event_type` | Fixed | `ai_disclosure_shown` |
| `page` | Request path | `/dashboard`, `/self-healing` |
| `session_id` | Browser session | `sess_a1b2c3d4` |
| `user_id` | Auth context (if logged in) | `user_123` or `anonymous` |
| `disclosure_version` | Semantic version of banner text | `1.0.0` |

### Backend Logging

The backend FastAPI application logs disclosure events via structured JSON logging (Uvicorn + `structlog`). Logs are captured by Docker logging driver (`json-file`) with rotation at 10MB, 3 files max.

```json
{"event": "ai_disclosure_shown", "page": "/dashboard", "timestamp": "2026-08-14T06:25:00Z", "level": "info", "logger": "compliance.disclosure"}
```

### Log Retention

- **Current policy:** 30 days rolling (Docker `json-file` driver, 3×10MB rotation)
- **CRA recommendation:** 6 months minimum for security-relevant logs (CRA Art. 13)
- **AI Act Art. 12:** Only mandatory for high-risk systems (QA-FRAMEWORK is limited risk — not required, but best practice)
- **Future:** Migrate to centralized logging (Grafana/Loki) for 6-month retention when scale demands
