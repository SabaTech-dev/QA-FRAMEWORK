# Groq — Terms of Use (Summary for Compliance)

**Source:** https://groq.com/terms-of-use
**Retrieved:** 2026-08-14
**Effective Date (per Groq):** October 15, 2025

## Key Points for QA-FRAMEWORK Compliance

1. **Website vs API:** Groq's website Terms of Use apply to groq.com. API usage is governed by the **Groq Services Agreement** (separate). QA-FRAMEWORK uses the API, so the Services Agreement governs.

2. **Commercial Use:** GroqCloud API explicitly permits commercial use. No restrictions on automated workloads or testing tools.

3. **Prohibited Uses (ToS §1):** Standard prohibitions — unlawful activities, IP infringement, reverse engineering, scraping. QA-FRAMEWORK does not engage in any prohibited activity.

4. **Acceptable Use Policy:** Groq maintains an AUP that prohibits generating harmful, illegal, or abusive content. QA-FRAMEWORK's use (security test generation, vulnerability analysis) is permissible.

5. **Data:** Groq processes API prompts for safety/abuse prevention. Data not stored beyond 30 days. QA-FRAMEWORK sends technical payloads (CVEs, test configs), not PII.

6. **GPAI Obligations:** Groq (as API provider hosting Llama models) holds GPAI provider obligations under Art. 53. QA-FRAMEWORK is a deployer.

## Conclusion

✅ **No ToS conflict.** Groq API permits QA-FRAMEWORK's commercial automated testing use case.
