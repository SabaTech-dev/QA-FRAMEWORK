## How tutorials differ from other docs

- **Tutorials** (this section): learning by doing — no prior knowledge assumed.
- **How-to guides**: solve a concrete task, assumes you know the basics.
- **Reference**: look up exact details while you work.
- **Explanation**: understand how the framework is designed.
